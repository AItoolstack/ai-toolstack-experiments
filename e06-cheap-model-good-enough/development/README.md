# E06 development material

Everything here comes from before the frozen evaluation on 29 October 2026. It is kept so the
path to the result can be checked. None of it is part of the result.

- `results/`, `analysis/`: pilot and preflight runs, from 25 to 29 October. The 25 October
  pilots include Llama 3.1 8B, which was replaced by GLM-5.3-Flash before the full run (see
  `../CHANGELOG.md`). Pilot keys differ from the audited final keys.
- `notes/`: working notes written during the pilots and the freeze (pilot reviews, preflight
  reviews, the resumption report, and an earlier results summary). Superseded by
  `../FULL-RESULTS-2026-10-29.md`.
- `reproduce-pilot.ipynb`, `make_figures_pilot.py`, `run-pilot.ps1`: tools from the pilot stage.

The 21 development items also appear in the final set. They are reported separately from the
81 held-out items because they were seen during these pilots.
